**[StrongInsight](https://github.com/JonathanContrerasM/StrongInsight)** — drop a [Strong](https://www.strong.app/) CSV export in the browser and get progression charts, a recovered training split, and a weakness engine that only reports what survives a significance test. No backend, no account, no telemetry.

`TypeScript` · `React` · `Vite` · `Tailwind CSS` · `Zod` · `Vitest` · `GitHub Actions`
